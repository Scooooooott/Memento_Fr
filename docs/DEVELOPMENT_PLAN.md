# 法语版本开发与验收计划

日期：2026-09-08。依据项目对话《读取法语词库设计》《读取法语词库设计 (2)》及其引用的最终 MVP 决策。

执行状态（2026-09-09）：backend、content、ui 三个子 agent 的实现与主 agent 集成均已完成；33 项自动化测试、大字体补充回归、真实进程恢复及内容升级验收通过。已交付 0.2.0 APK，逐项结论和适用边界见 [验收报告](ACCEPTANCE_REPORT.md)。

## 最终成品目标

自用的原生 Android、离线 fr-FR 背词 App。保留原型的白底绿色视觉、中文操作提示与 EN/ES 释义。法语是唯一学习语言。无账户、云同步、在线词库、导入、测试题或社交功能。

本轮交付可安装 APK 与完整学习闭环；先使用 20–50 个审校过的法语开发词条，明确标注词库范围，不能把现有教材 OCR 当作已校对词库。完整教材 A0–A1 词库与真人音频是后续内容版本，原始 PDF/OCR 保留不变。

## 验收标准

1. 首页数量、今日完成、词书进度来自数据库，不保留示例统计。
2. 内容库与用户库独立；长期稳定 lexeme_uid 关联。内容升级保留学习数据。
3. 新词默认每天 10 个，设置范围 0–100；每日额度跨 session 累计。所有到期复习与当前词书新词合并 shuffle，队列固定且持久化。
4. 退出、旋转和进程重启恢复当前词、队列与答案状态；设置修改只影响下一轮。
5. 正面不泄露释义；答案最多两个核心义项，显示 EN/ES、法语例句与关键形式。详情可查看所有义项、例句与已收录变位。
6. 忘记/模糊/记得/很熟对应 FSRS Again/Hard/Good/Easy；评分、卡片、日志和队列推进同一事务，重复提交不重复计数。Again 不重新插入当前队列。
7. 本轮总结、重点复习词和统计来自实际记录；没有任务时显示空状态。
8. 设置持久保存每日新词、词书、IPA、EN/ES、自动播放（从不/新词/全部）、TTS 回退。至少保留一种释义。
9. 发音优先本地文件，仅使用离线 fr-FR TTS 回退，缺少语音包明确提示。
10. 单元测试覆盖调度和边界；数据库/Compose 功能测试覆盖开始、揭示、评分、恢复、设置、详情、完成。构建 APK、lint，并保存验收证据。

## 分工

- backend agent：用户 SQLite、固定 session、每日额度、FSRS 与领域测试。
- content agent：30–50 个法语词条、规范内容 SQLite、生成/校验工具、内容读取层。
- ui agent：Compose 首页、学习、详情、总结、设置及导航和真实状态。
- 主 agent：共享接口、音频、构建环境隔离、集成修复、Android 功能测试与独立内容验收。

## 文件边界

所有新增与修改均在 L:\Words 内。已有外部工具可只读使用；Gradle 用户缓存、临时目录、Android 用户目录、模拟器数据、日志均重定向项目内。不修改外部 SDK/系统配置；需要 SDK 组件时安装在项目内。

## 实现选择

沿用 Kotlin/Compose，SQLiteOpenHelper 管理用户库，预构建只读 SQLite 管理内容，避免额外 ORM 编译链。仓储接口隔离存储实现；持久化事务承担一致性，UI 在 IO 调度器调用仓储。
