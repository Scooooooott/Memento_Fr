# 中英西释义读取契约（App 0.3.0）

本窗口仅修改 Android 读取和显示逻辑，不修改正式词库、生成工具或词条内容。供词库窗口补充中文时对接。

## SQLite 字段

| 表 | 新增字段 | 含义 |
| --- | --- | --- |
| `sense` | `chinese TEXT` | 该义项的中文释义，与同一行 `english` / `spanish` 对应 |
| `example` | `chinese TEXT` | 同一行 `french` 例句的中文译文 |

推荐使用 `TEXT NOT NULL DEFAULT ''`。读取也兼容 `NULL`、空字符串，以及旧库完全没有该列的情况，均视为未收录中文。禁止用英语或西班牙语值冒充中文。

新增字段不改变 `lexeme_uid`、`sense_id`、`example_id`、关联关系及排序。其他现有必需列、`content_meta.language = fr-FR` 与各表结构沿用既有契约。内容库接受 `PRAGMA user_version = 1` 或 `2`；推荐新增中文后设为 `2`，同时容许版本 1 上的可选加列。未提供完整兼容契约的未来版本仍拒绝读取。

若源文件采用 JSON，同名 `chinese` 可分别放在每个义项和例句对象内；具体源到 SQLite 的写入由词库窗口负责，App 不读取 JSON。

## 显示规则

- 释义与例句译文按中文、EN、ES 顺序显示已选且非空的内容；法语例句本身保持显示。
- 设置新增“中文 · ZH”，至少保留中英西中的一种。只选中文也允许保存。
- 当前所选语言都没有内容时明确显示“所选语言的释义暂未收录”或“所选语言的译文暂未收录”；不自动打开未选择的语言。
- 词库搜索支持法语及中英西释义。列表优先显示所选语言中可用的中文，再 EN、ES；完全缺失时显示缺失提示。
- 答案仍最多显示两个核心义项；详情展示全部已收录内容。中文开关同时控制释义和例句译文。

## 用户数据兼容

用户库从 v1 非破坏升级到 v2，设置新增 `show_chinese`，并取消每日新词 100 上限。全局设置新增中文默认开启，原英西开关保留。老的未完成 session 的设置快照缺少 `showChinese` 时按 `false` 读取，确保当前轮显示不被升级改变；新设置从下一轮生效。

中文兼容测试使用测试 APK 内的独立小样，不写入正式 `app/src/main/assets/french_content.db`。当前正式词库中文是否齐全，由内容版本决定。
